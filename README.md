# 국문 고전소설 DB (공개판)

TEI로 태깅한 국문 고전소설 원문과, 국문장편소설 여섯 편(창선감의록, 쌍천기봉, 유씨삼대록, 임씨삼대록, 현몽쌍룡기, 조씨삼대록)을 견주어 만든 '국문장편의 공유 세계' 화면입니다.

**사이트 주소: https://kangeunkim9.github.io/classic-novel-db/**

- `index.html` : 첫 화면과 원문 읽기·검색
- `world.js`, `data/world.js` : 공유 세계(세계의 요소, 세계의 법칙, 응보의 질서, 역사 연표, 고사·경전)
- `info.js` : 화면 전환과 휴대폰 읽기
- `data/*.js` : 작품별 원문과 태그

## 알아 둘 점

- 이 공개판에는 현대어역 본문이 들어 있지 않습니다. 공유 세계의 근거 대목은 각 작품 현대어역에서 짧게 인용한 것이며, 그 저작권은 각 번역서에 있습니다.
- 공유 세계의 항목 정의, 법칙 판정, 사례 분류는 1차 정리 결과입니다. '검토' 표시가 붙은 것은 확인이 더 필요합니다.

기획·구축: 김강은 (성균관대학교 국어국문학과 BK21 교육연구단)
